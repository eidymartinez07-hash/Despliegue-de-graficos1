Concepto 1

¿Qué es <canvas>?

La etiqueta <canvas> crea un área rectangular donde JavaScript puede dibujar. La etiqueta reserva el espacio; el código JavaScript decide qué aparece dentro.

El contexto 2D

Con canvas.getContext("2d") obtenemos herramientas para dibujar líneas, rectángulos, círculos, texto e imágenes. Las coordenadas empiezan en la esquina superior izquierda: (0, 0). 

const canvas = document.querySelector("canvas");
const ctx = canvas.getContext("2d");

ctx.fillStyle = "#f27a61";
ctx.fillRect(20, 20, 100, 60);

El ejemplo obtiene el contexto 2D, elige un color y dibuja un rectángulo.

Concepto 2

Fundamentos de p5.js

p5.js es una biblioteca de JavaScript para crear dibujos, animaciones e interacciones de forma accesible.

setup()

Se ejecuta una vez al iniciar. Normalmente crea el lienzo con createCanvas(ancho, alto).

draw()

Se repite muchas veces por segundo. Al redibujar la escena, permite crear animaciones.

Interacción

Variables como mouseX y mouseY permiten responder a la posición del ratón. 

function setup() {
  createCanvas(400, 200);
}

function draw() {
  background(245, 239, 226);
  circle(mouseX, mouseY, 40);
}

Este ejemplo de p5.js crea un círculo que sigue al ratón.
